# Специфікації фіч

Спершу спека, потім код. Кожна фіча має короткий файл (до пів сторінки), який
відповідає на запитання «що має робити і коли це готово». За спекою пишуть код
розробники та ШІ-агенти, за нею ж пишеться E2E-тест.

## Як користуватись

1. Перед новою фічею скопіюй `_template.md` і заповни.
2. У PR посилайся на спеку. Якщо поведінка змінилась, оновлюй **спеку, а не лише код**.
3. Критерії приймання мають бути перевірними: кожен пункт — це E2E-сценарій.
