# F5. Пошук аудиторій і викладачів

**Стан:** бекенд є, UI в плані · **Відповідальні:** мобільний, бекенд, дизайн

## Навіщо
Швидко знайти, де аудиторія, і в якому вона корпусі.

## Як це працює
- Поле пошуку на екрані «Аудиторії», фільтри за корпусом.
- Результат: аудиторія з корпусом і адресою, перехід до маршруту.
- Без запиту показується список корпусів.
- Пошук нечутливий до регістру, максимум 20 результатів.

## API
| Метод і шлях | Для чого |
|---|---|
| `GET /classrooms?q=` | Аудиторії за частиною номера |
| `GET /teachers?q=` | Викладачі за частиною імені |

Аудиторія повертається як `id`, `number`, `label` (`номер/корпус`), `building` (`code`, `name`).

## Критерії приймання
- [ ] Запит `N1` повертає аудиторії, номер яких містить `N1`, не більше 20.
- [ ] Регістр запиту не впливає на результат.
- [ ] Порожній запит повертає список без помилки.
- [ ] Для кожної аудиторії видно корпус.

## Відкриті питання
- Макет показує адресу корпусу і фільтри за корпусом. У відповіді `GET /classrooms` адреси поки немає, потрібен фільтр за корпусом.
- Окремий екран пошуку викладачів: чи потрібен у MVP.
