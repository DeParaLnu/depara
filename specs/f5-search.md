# F5. Пошук аудиторій і викладачів

**Стан:** бекенд є, UI в плані · **Відповідальні:** мобільний, бекенд, дизайн

## Навіщо
Швидко знайти, де аудиторія, і в якому вона корпусі.

## Як це працює
- Поле пошуку на екрані «Аудиторії», фільтри за корпусом.
- Результат: аудиторія з корпусом і адресою, перехід до маршруту.
- Без запиту показується список корпусів.
- Пошук нечутливий до регістру, максимум 20 результатів.

## API
| Метод і шлях | Для чого |
|---|---|
| `GET /classrooms?q=&building=` | Аудиторії за частиною номера (`q`) і/або корпусом (`building` = літера корпусу, регістр не важливий). Невідомий корпус дає порожній список |
| `GET /buildings` | Довідник усіх корпусів (`code`, `name`, `address`), за літерою. Для чіпів-фільтрів і блоку «Корпуси» |
| `GET /teachers?q=` | Викладачі за частиною імені |

Повторений параметр (`building` або `q` двічі) дає `400 INVALID_QUERY`.

Аудиторія повертається як `id`, `number`, `label` (`номер/корпус`), `building` (`code`, `name`, `address`).

## Критерії приймання
- [ ] Запит `N1` повертає аудиторії, номер яких містить `N1`, не більше 20.
- [ ] Регістр запиту не впливає на результат.
- [ ] Порожній запит повертає список без помилки.
- [ ] Для кожної аудиторії видно корпус і його адресу.
- [ ] `GET /buildings` повертає всі корпуси з адресою, лише для авторизованих.
- [ ] `building=Т` повертає лише аудиторії корпусу Т; разом з `q` фільтри діють одночасно.

## Відкриті питання
- Окремий екран пошуку викладачів: чи потрібен у MVP.
